# Library Management System

This project is a simple Library Management System developed using Python.
It uses a dictionary-based approach to manage book records and follows a menu-driven structure.

## Features

* Add new books to the library
* View available books
* Issue books with student name and issue date
* Return books with fine calculation for late submission
* Tracks issued books using dictionary

## Fine System

* 1st week → ₹10 per day
* 2nd week → ₹20 per day
* 3rd week → ₹60 per day
* Fine increases week by week

## Project Structure

* `main.py` → Handles menu and user interaction
* `library_ops.py` → Contains all functions and logic
* `data.py` → Stores book records and issued book data

## Technologies Used

* Python
* Dictionary
* Functions
* Date handling (datetime module)

## How to Run

1. Open the project folder
2. Run `main.py`
3. Use the menu options
